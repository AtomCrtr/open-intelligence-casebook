# Contribuer

Ce dépôt est avant tout un portfolio analytique. Les contributions utiles concernent la correction factuelle, la reproductibilité, l'accessibilité, les liens cassés, les erreurs de mise en page ou la clarification méthodologique.

Merci de :

1. citer précisément la source ou le passage concerné ;
2. distinguer correction factuelle et désaccord analytique ;
3. ne jamais soumettre de secret, donnée personnelle inutile ou dataset dont les droits de redistribution sont incertains ;
4. privilégier une issue ou une pull request courte et vérifiable.
