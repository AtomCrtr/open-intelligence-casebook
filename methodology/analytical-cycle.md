# Cycle analytique commun

Chaque casebook part d'une **question décisionnelle**, pas d'une accumulation de données.

```text
Question -> besoins de renseignement -> collecte passive -> registre des sources
-> normalisation -> évaluation des preuves -> hypothèses concurrentes
-> scénarios / indicateurs -> jugement -> recommandation conditionnelle
```

La chaîne de preuve sépare systématiquement : **ce qui est observé**, **ce qui est rapporté par une source**, **ce qui est corroboré**, **ce qui est inféré**, **ce qui reste une hypothèse** et **ce qui n'est pas démontré**.

L'objectif n'est pas de produire une certitude artificielle, mais une conclusion proportionnée aux preuves disponibles.
